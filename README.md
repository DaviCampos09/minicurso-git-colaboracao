# Minicurso Git & GitHub — Aula 2

Repositório utilizado na atividade prática de colaboração
do minicurso de Git e GitHub da DataLab.

## Objetivo

Praticar o uso de Issues, Forks, Branches,
Commits e Pull Requests.

## Participantes

Cada participante deverá adicionar um arquivo
de apresentação na pasta `participantes/`.

As contribuições serão integradas à branch `main`
por meio de Pull Requests.
